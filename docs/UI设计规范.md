# 管焊圈 UI 设计规范

本规范适用于微信小程序及管理后台。后续 AI 开始修改页面、组件、样式和运营内容前，必须先阅读本文。主参考为 2026-11-13 提供的首页、招工详情、求职简历和个人中心截图。

## 1. 设计方向

蓝白主色、浅灰页面背景、橙色薪资、清晰的卡片分组。以岗位和主操作为中心，去掉重复标题、口号、教学段落、装饰性说明。表单标签、错误原因、审核状态、隐私与扣费确认必须保留。

- 小程序继续使用 Vue 3 + uni-app、现有 uni-ui / ColorUI；后台复用 Pure Admin 与 Element Plus。
- 使用 uni-icons 的同一家族图标，不混入 emoji 或新的图标库。无需引入 React 专用库。
- 页面数据不伪造认证、会员身份、浏览量、余额或联系人头像。没有头像时使用统一的中性图标。
- 所有新页面优先复用 `job-card`、`job-form`、`page-state`、`region-picker`、`option-picker`、`selection-field`、`selection-sheet` 和 `cu-custom`。
- 公共导航统一采用 Vue 3 命名插槽 `<template #content>`。

## 2. 设计令牌

唯一的全局样式入口：`app/src/styles/tokens.scss`。颜色使用语义变量，新增变体先补令牌。

| 角色 | 变量 | 值 |
| --- | --- | --- |
| 主色、主操作 | `--primary` | `#2563EB` |
| 主色浅底 | `--primary-soft` | `#EDF4FF` |
| 薪资 | `--salary` | `#ED5B0B` |
| 成功、认证状态 | `--success` | `#19A55A` |
| 危险操作 | `--danger` | `#E5484D` |
| 标题 | `--ink` | `#182131` |
| 正文 | `--text` | `#3F4B5D` |
| 次要文字 | `--muted` | `#657287` |
| 页面底色 | `--canvas` | `#F7F8FA` |
| 分隔线 | `--line` | `#EDF0F4` |
| 卡片圆角 | `--radius` | `24rpx` |

采用系统中文字体，不下载字体。共享组件与核心页面使用语义字号：`--font-caption` 12px、`--font-small` 13px、`--font-body` 14px、`--font-control` 15px、`--font-heading` 18px、`--font-title` 20px、`--font-display` 24px，避免窄屏字号随 rpx 缩小。辅助文字不承载唯一的关键操作。

页面左右留白 32rpx；卡片内边距 28–32rpx；卡片间距 24rpx。间距以 8rpx 为基数。主按钮至少 48px 高、圆角 20rpx，返回与筛选触发区至少 44px；小型电话按钮采用胶囊形。标签圆角 8rpx，技能标签可用胶囊形。卡片阴影统一使用 `--shadow-card`，避免叠加重阴影。

## 3. 页面结构

### 首页

白色导航与搜索筛选区 → 后台轮播 → 四类快捷入口 → 招工卡片。地区统一在顶部搜索区选择并显示当前范围；下方筛选行包含工种、薪资、时间与筛选/重置操作。搜索支持回车提交，快捷入口执行实际筛选。

底部主导航为首页、发布招工、我的。个人资料与管理功能从“我的”进入。

小程序默认进入首页。游客可选择地区和筛选条件，列表区域通过 `auth-gate` 展示“登录后查看岗位”；会话校验完成且登录成功后才请求和显示岗位列表。登录返回首页时应用已选条件。退出登录清空岗位数据并返回首页；接口层同步要求用户鉴权。

岗位卡片依次呈现名称与薪资、业务标签、地区与时间、联系人与查看电话。急招用橙色细边和标签，置顶/认证用浅蓝标签。不能仅依赖颜色说明状态。卡片和电话按钮都进入详情，解锁扣费只在详情确认后执行。

轮播图从 `/banners/list` 读取，建议宽高比约 2.5:1。无图时显示后台标题的蓝色占位；图片加载失败不显示破图。默认不自动播放。后台可以停用轮播，不在前端硬编码营销文案。

### 招工详情

白色分区，灰色区间留白，蓝色竖线标题。工作信息、岗位要求、待遇、发布方分组。底部固定收藏、分享、查看电话/一键拨号。报名保留在联系卡片中，防止和电话操作争夺视觉主次。

查看电话先展示后端返回的积分成本；电话已解锁才调用拨号。保留举报、信用查询和安全提示。页面不能因固定底栏遮住最后一项内容。

### 简历

通过“我的 → 我的简历”进入概览：蓝色求职状态卡、个人资料、工种技能、求职意向、刷新按钮。概览使用带返回按钮的二级页面，编辑进入独立页面。状态切换即时保存，失败回滚；刷新不重新提交内容审核。真正修改内容后仍进入审核流程。

### 个人中心

蓝色身份区 → 白色钱包卡 → 我的招工/简历/收藏 → 后台配置的常用服务 → 设置与退出。钱包失败显示破折号与重试，不能显示虚假的零余额。认证标记仅在后端确认时展示。

### 其他页面与后台

后台面向 PC 浏览器，基于 Pure-Admin 官方精简版（MIT）二次开发，复用上游侧栏、标签页、菜单搜索、主题和共享组件。业务页面位于 `admin/src/views/guanhanquan/`，通过 `admin/src/api/guanhanquan.js` 访问 PostgreSQL API。新增菜单在 `admin/src/router/modules/` 配置，后台图标使用框架自带的 Remix 图标并离线打包。费用与奖励按用途分组，统计与待办仅展示接口返回的数据。

发布、认证、钱包、培训、保险、消息、收藏、管理等页面沿用相同令牌、按钮和卡片圆角。搜索与分类岗位共用招工卡片。后台使用白色侧栏、浅蓝选中态、圆角内容区及 Element Plus 表单/表格。

## 4. 交互与可访问性

- 主操作用原生 `button`；输入框提供可访问名称，保留可见标签。图标操作提供 `aria-label`。
- 交互反馈使用 160ms 的透明度或颜色变化；内容进入动画 240ms，使用 `--ease-out`。底部导航选中图标使用浅蓝底，切换为 180ms 颜色过渡；重复点击当前导航不重新跳转。避免让布局抖动的尺寸动画。
- 支持 `prefers-reduced-motion`。加载骨架允许呼吸动画，其他地方不做循环装饰动画。
- 新请求需要 loading、可重试的 error、真实 empty 状态。错误不能伪装成“暂无内容”。
- 表单提交禁用重复操作；删除、扣积分、支付、注销保留明确后果提示。
- 选择字段采用整行点击：左侧可见标签，右侧当前值与箭头。新建未选时不把第一项误标为已选。已有地区按后端地址回显路径。输入型字段与选择型字段的外观和点击反馈要清晰。
- 筛选条件与排序分为两行；发布时间收进单选面板，排序采用互斥选中态。更改查询后显示加载状态，分页失败保留已加载岗位并在列表末尾重试。
- 表单保存成功后能完整回填已提交字段。上传失败保留原图片，上传中禁用提交；新建简历不展示删除按钮。认证页加载失败必须可重试。
- 搜索用请求序号隔离过时响应；分页失败不能提前递增页码。
- 固定操作区叠加 `env(safe-area-inset-bottom)`；正文留出底栏高度。顶部使用真实状态栏和微信胶囊尺寸。
- 地区选择统一使用底部级联面板：省 → 市 → 区县，顶部保留可返回修改的已选路径，选完末级自动收起。筛选允许全国、全省和全市；发布与认证表单选择完整地区。关闭面板不改变已提交的值，再次打开回显当前路径。
- 至少检查 320/390px 竖屏与横屏，长岗位名称、长薪资、空头像、空数据、接口失败均不得横向溢出。
- H5 的 rpx 在超过 480px 的视口按 390px 基准计算，避免横屏时文字和控件随屏宽放大；布局仍使用 flex/grid 与百分比。微信端继续按原生 rpx 规则布局。
- H5 视口达到 600px 时，页面居中、最大宽度 560px，顶部和底部固定操作与正文同宽；相关全局规则需覆盖组件 scoped 样式。筛选触发器复用原生 button，保留键盘焦点和可访问名称。

## 5. 后台内容契约

运营内容默认值只在 `cloudfunctions/api/content.js` 定义，前端 `utils/content.js` 负责响应式读取与 60 秒内存缓存。首页下拉刷新强制更新；进入其他主页面时按缓存有效期更新。

| 内容 | 读取来源 | 管理入口 |
| --- | --- | --- |
| 品牌名、搜索提示、急招/置顶/认证标签、底栏名称、安全提醒 | `GET /content/ui` | 小程序内容 → 页面内容 |
| 证书、工作年限、到岗时间、企业规模、结算/食宿/路费、举报类型、日薪和时间筛选 | `GET /content/ui` 的 `dictionaries` | 小程序内容 → 标签选项 |
| 首页专区和个人中心服务名称、顺序、开关 | `GET /content/ui` | 小程序内容 → 快捷入口 |
| 常见问题 | `GET /content/ui` | 小程序内容 → 常见问题 |
| 工种名称、顺序、启停 | `GET /categories/list` | 工种管理 |
| 省、市、区县与行政代码 | `GET /regions/tree` | 后端 `data/area-list.json` 数据快照 |
| 轮播图、跳转、标题、顺序、启停 | `GET /banners/list` | 轮播图 |
| 职位、薪资、福利、用户、简历、费用 | 原业务接口 | 原审核/运营入口 |

管理员写入口：`PUT /admin/content`、`POST /admin/categories`，均要求管理员鉴权。页面操作名称（例如保存、取消、返回）、字段标签和业务状态语义由代码负责；不能让运营配置改变扣费、审核、权限或路由逻辑。

字典一项为 `{ value, label }`：value 是稳定业务值，label 是显示名称。固定数字枚举允许改名、排序，不允许改 value 或移除；动态文本选项可增删。picker 提交 value，禁止用选中位置加一生成业务值。历史选项不再提供时仍以原值回显。

工种首次保存会迁入默认列表，保留已有 ID。改名保留历史名称，以便查询已有简历；停用仅隐藏选择入口，不删除历史岗位。薪资排序和筛选按日薪比较，兼容旧记录缺省日薪单位；小时薪、月薪不会混入日薪结果。

地区树按会话缓存，由后端提供行政代码和显示名称。筛选提交 `regionCode`，后端组合城市与区县，区分同名区县，并兼容已有岗位的城市简称。发布地区保存完整路径。地区数据采用 `@vant/area-data` 2.2.0（MIT），来源与更新方式见 `cloudfunctions/api/data/README.md`。

## 6. 组件选型与成熟实现参考

以下规则基于官方文档与当前安装的 uni-ui 1.5.12 源码核对（2026-11-13）。新增界面先确定信息结构与选择方式，再决定组件。

| 场景 | 组件与交互 | 本项目落点 |
| --- | --- | --- |
| 省市区、层级分类 | 底部 Popup + Cascader；路径标签回退，下级独立滚动 | `region-picker` 复用 `uni-data-pickerview`，`selection-sheet` 复用 `uni-popup` |
| 工种、薪资范围、时间等单选筛选 | 单选列表显示当前勾选，点选立即应用，遮罩/关闭取消 | `option-picker`，与地区使用同一弹层外观 |
| 证书、福利等少量多选 | 可点击标签组，明确选中态；真实状态用 Switch | 复用原生 checkbox/switch，选项来自后端字典 |
| 日期与连续数值 | 原生日期/数值 Picker，输入数字使用数字键盘 | 表单字段 |
| 岗位列表 | 一张卡片对应一个岗位；薪资是第一层辅助信息，标签只承载业务事实 | `job-card`，骨架/空状态/重试由 `page-state` 负责 |
| 联系、收藏与分享 | 底部操作栏；一个主操作、次操作图标，预留安全区 | 岗位详情 |
| 认证、发布、简历编辑 | 分组表单；可见字段标签、就近校验、提交反馈 | `job-form` 及独立编辑页 |
| 常见问题 | 可展开列表，按需阅读内容 | `uni-collapse` 或等价的现有可展开条目 |
| 扣费、删除与永久提交 | Dialog 明确展示后果与成本，确认后执行 | 保留原生确认弹窗 |

面板标题与关闭按钮固定，列表独立滚动；选项至少 48px 高。少量单选项的面板按内容自适应高度，级联选择保留稳定列表高度。弹层复用组件库的淡入/上移过渡，适配底部安全区和横屏。uni-app 子组件皮肤使用有作用域的 `:deep()`，不修改 node_modules。

参考源码与文档：

- [uni-data-picker 官方文档](https://uniapp.dcloud.net.cn/component/uniui/uni-data-picker.html)：数据驱动的级联选择与路径回显。
- [uni-ui 源码](https://github.com/dcloudio/uni-ui/tree/master/uni_modules/uni-data-picker)：本项目复用其内部 `uni-data-pickerview`；适配器使用与原父组件一致的 `updateData` 数据契约，升级组件库时复测。
- [Vant Weapp Cascader 示例源码](https://github.com/vant-ui/vant-weapp/blob/dev/packages/cascader/README.md)：Field + Popup + Cascader 组合与完成/关闭语义。
- [Vant Weapp DropdownMenu 示例源码](https://github.com/vant-ui/vant-weapp/blob/dev/packages/dropdown-menu/README.md)：单选筛选、当前值回显与选中态。

## 8. 微信登录与个人资料

- 首页岗位列表、搜索结果、发布招工、我的、简历与个人资料使用统一 `auth-gate`；会话校验期间展示加载状态，未登录时显示明确的登录主操作。首页导航、地区、筛选和运营入口保持可见。
- 小程序原生 slot 内部存在自动加载私有接口的子组件时，页面同时使用登录态 `v-if` 控制其创建，不能只依赖 slot 的显示条件。
- 微信端由 `uni.login` 取得 code，服务端换取 OpenID 并签发业务令牌。身份由后端确认；不得相信客户端传入的 OpenID，不得把 AppSecret、session_key 发送到小程序。
- 头像、昵称由用户主动提供：头像使用原生 `button open-type="chooseAvatar"`，昵称使用 `input type="nickname"`。昵称通过原生 form 提交值读取，遵循微信安全检测结果；不通过旧版 `getUserProfile` 静默获取个人资料。
- 首次登录资料不全时展示可跳过的资料完善步骤。头像上传成功后才能保存，失败保留原头像；昵称为 1–20 个字。手机号独立在设置中授权。
- 登录保存内部来源路由，成功后返回原页面；重复点击和并发 401 只弹一个登录提示。退出或登录失效时同时清理持久化令牌与 Vuex 用户信息。清除普通缓存保留账号会话。
- 头像与昵称表单只维护一份 `profile-form`，登录完善和“我的 → 个人资料”共用；保存后由后端返回的用户资料更新界面。已有依赖即可实现，不额外引入认证或状态管理库。
- 微信头像昵称组件最低基础库为 2.21.2，建议在包含 2.24.4+ 安全检测行为的基础库与真机上验收。H5 开发登录仅用于本地接口与界面测试。

官方参考：[小程序登录](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)、[头像昵称填写](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/userProfile.html)、[button](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)、[input](https://developers.weixin.qq.com/miniprogram/dev/component/input.html)。

## 9. 导航、反馈与二级页面

底部主导航固定为首页、发布招工、我的，使用白底、22px 顶部圆角和轻阴影。普通状态采用线框图标，当前页面采用实心图标、浅蓝胶囊底和加粗蓝色文字。主导航内容高度由 `--tabbar-height: 69px` 维护，叠加底部安全区；正文和发布表单复用此值预留空间。

招工管理和个人简历均从“我的”进入，使用带返回按钮的二级页面。招工管理集中展示企业资料、发布招工、岗位管理、报名与工人查询入口；账号、钱包及设置统一由个人中心进入。普通启动与开发者工具的默认启动条件都指向首页。

| 交互 | 规范 |
| --- | --- |
| 导航按压 | 原生 `hover-class`，立即反馈，松手保留 120ms；图标区缩至 0.88 并改变底色 |
| 当前导航图标 | 260ms 进入动画，位移 3px、缩放 0.86 → 1；不循环播放 |
| 首页和个人中心快捷入口 | 160ms 按压缩放至 0.92；选中筛选保留状态标识 |
| 主按钮 | 至少 48px 高，按压缩放至 0.985；提交期间禁用重复操作 |
| 小型操作 | 编辑、返回、详情次操作、管理按钮至少 44px 触控区 |
| 客服问答 | 复用现有 `uni-collapse` 手风琴；原生按钮标题、展开语义、键盘操作，箭头 220ms 旋转 |
| 减少动态效果 | 移除位移、缩放和进入动画，保留颜色与状态变化 |

导航路由在跳转完成前防重复触发；失败给出可重试提示。选中态基于实际页面，不提前切换到尚未打开的页面。导航和问答在 H5 下提供键盘焦点与 Enter/Space 操作。

钱包、认证、消息、培训、信用查询等二级页面沿用相同字号令牌与触控尺寸。H5 中统一重置框架按钮的默认伪元素边框，由组件自身控制边框，避免额外描边。钱包等待接口返回后才显示金额、费用和奖励；账户与收支记录分别提供失败重试。登录门槛、加载态、空状态和业务状态不可用视觉占位数据代替。

岗位管理的状态筛选使用至少 44px 高的互斥按钮，当前项同时以字重与底色表示。置顶与刷新按接口返回的费用确认，零费用按零显示，费用未知时禁用收费操作并提供重试；确认及提交期间阻止重复扣费请求。简历库搜索固定本次已提交条件，新的搜索覆盖旧请求，分页失败保留已加载内容并重试同一页。
