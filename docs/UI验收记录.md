# UI 验收记录

日期：2026-11-13。范围：小程序整体视觉改版、地区级联、共享选择组件、搜索与表单体验、后台运营内容配置。

## 实现与参考

- 复用当前 uni-ui 的 `uni-popup`、`uni-data-pickerview` 和 uni-icons，统一面板、选择字段、卡片与页面状态；小程序未新增运行时依赖。
- 地区采用省 → 市 → 区县级联，筛选支持全国、全省和全市；表单要求完整路径。支持回退修改与当前选择回显。
- 工种、薪资、时间、证书等单选采用一致的勾选列表；短列表按内容适配高度。
- 搜索把筛选与排序分开；新查询显示加载状态，分页失败保留已有列表并提供重试。
- 发布、简历、认证表单统一可见标签和选择行，处理提交中、上传失败及保存回填。企业资料保存涵盖电话、地区、详细地址、规模、简介和图片。
- 首页、详情、简历与个人中心使用统一的蓝白配色、橙色薪资、间距与图标；底栏和弹层预留安全区。
- 运营名称、标签、字典与入口由后端配置返回，稳定业务值与显示名称分离。
- 组件选择依据与官方参考链接已收录在 [UI设计规范](UI设计规范.md)。`AGENTS.md` 已要求后续 UI 修改先读规范。
