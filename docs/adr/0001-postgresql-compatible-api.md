# PostgreSQL 与现有业务接口兼容

采用 PostgreSQL 17 保存关系数据，在 Fastify 官方 MIT 脚手架上开发独立 HTTP 服务，复用现有业务 handlers 与 Element Plus 后台。核心字段映射到带约束、外键和索引的关系表，兼容层保留前端使用的字符串 ID、字段名称及毫秒时间格式，避免同时重写所有页面和审核流程。JSONB 仅保存配置值、原始支付资料及可选扩展字段。

现有 handlers 包含跨表读改写以及 GET 内的浏览计数、过期处理；初期将完整业务请求放入数据库事务，通过 PostgreSQL advisory transaction lock 串行化这些流程。该选择优先保证扣费、审核、签到和审计的一致性，吞吐量会受到限制；后续可将纯读取接口分离、钱包操作收敛到带行锁的领域服务，逐步缩小锁粒度。支付回调独立验签后进入同一事务边界，避免重复入账。
